# 🩺 Breast Cancer Prediction using Support Vector Machine (SVM)

This project applies **Machine Learning** techniques to predict **Breast Cancer diagnosis** using the **Support Vector Machine (SVM)** algorithm.  
The model classifies tumors as **Benign** or **Malignant** based on real medical data.

## 🎯 Project Objective

Early detection of breast cancer is critical for successful treatment.  
This project aims to build an intelligent system that predicts whether a tumor is **Benign** or **Malignant** using machine learning.

---

## 🧠 Model & Techniques Used

- Algorithm: Support Vector Machine (SVM)
- Data Processing:
  - Data Cleaning
  - Feature Selection
  - Train/Test Split
  - Feature Scaling
- Model Evaluation:
  - Accuracy Score
  - Confusion Matrix
  - Classification Report

---

## 🔬 Workflow

1. Load dataset  
2. Perform Exploratory Data Analysis (EDA)  
3. Preprocess the data  
4. Train SVM model  
5. Evaluate model performance  
6. Make predictions and analyze results  

---

## 📊 Results

The model successfully classifies breast cancer tumors into:
- Benign
- Malignant

Performance is validated using accuracy metrics and visualizations.
